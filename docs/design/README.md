# Replay page design

The design the replay page is built to match (open-replay-studio #1 to #12).

- `openreplaymock.html`: the mockup. Open it in a browser; it runs on its own with demo data.
- `scene.js`: the demo video it draws. Must sit next to the HTML file.
- `replay-1440x880.png`: the mockup at 1440 x 880.

The tickets' line numbers refer to `openreplaymock.html` as it is here.

Not part of the target: the Settings panel behind the gear, the demo data, and the demo "click to go on air".
The Studio must look and behave like the mockup; its code does not have to be the mockup's.
